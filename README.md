# 🐻✨ Jelly Blocks! Kids Tetris Adventure

A delightful, super-cute Web Tetris game designed specially for **kids under 8**! Featuring cheerful synthesized music & sound effects, bouncing jelly animations, friendly animal companions, and gentle kid-friendly gameplay.

🎮 **Live Play**: [https://chouhaohsu-tech.github.io/Tetris/](https://chouhaohsu-tech.github.io/Tetris/)

---

## 🌟 Kid-Friendly Features

1. **Gentle & Forgiving Gameplay**:
   - **Story / Kids Mode (Default)**: Slower fall speed, extra generous lock delay so little hands have time to adjust and wiggle pieces.
   - **🎈 Zen Mode**: Never get a sad Game Over! If blocks reach the ceiling, a magical fairy dust blast clears the top rows so fun continues forever!
   - **🏆 Classic Mode**: Traditional progression for older siblings and parents.
2. **Kid Power-Ups**:
   - **↩️ Oops / Undo Button**: Accidental misdrop? Tap "Oops!" to restore the board!
   - **🪄 Magic Star Wand**: Clears the bottom line when the stack gets tricky.
3. **Cute Aesthetic & Expressions**:
   - **Smiling Jelly Blocks**: Every piece has cute smiling eyes, gloss shine, and reacts with squash & stretch physics!
   - **🐰 Bubu the Bunny Mascot**: Cheers for you, claps, dances with stars, and giggles when you tap him!
   - **3 Cute Themes**:
     - 🍬 Candy Land (Cotton Candy & Gumdrop)
     - 🐱 Animal Friends (Puppy, Kitty, Panda, Froggy)
     - 🚀 Galaxy Stars (Smiling planets and cosmic sparkles)
4. **Rich Sound & Animations**:
   - 100% synthesized Web Audio API sounds (pop, chime, cartoon boing, and victory fanfares).
   - Joyful kalimba / music box procedural background music with one-tap mute.
   - Speech synthesis cheering voice ("Awesome!", "Mega Tetris!").
   - Fullscreen fireworks, star bursts, heart confetti, and rainbow waves!
5. **Cross-Platform Responsive Design**:
   - **iPhone / Mobile**: Large tactile thumb buttons + intuitive swipe & tap gestures on canvas.
   - **iPad / Tablet**: Spacious dual-handed controller layout and safe-area notch support.
   - **PC / Mac**: Full keyboard navigation (Arrow keys, WASD, Space, Shift/C, U, M).

## 🕹️ Controls

| Action | PC Keyboard | iPhone / iPad Touch |
| :--- | :--- | :--- |
| **Move Left / Right** | ⬅️ / ➡️ or `A` / `D` | ◀ / ▶ Buttons or Swipe Left / Right |
| **Spin / Rotate** | ⬆️ / `W` / `X` (CW), `Z` (CCW) | 🔄 Spin / ↩ Left or Tap Board |
| **Soft Drop** | ⬇️ or `S` | ▼ Down Button or Swipe Down |
| **Slam Drop** | Spacebar | ⚡ DROP Button |
| **Pocket / Hold** | `C` or `Shift` | 🎒 HOLD Button |
| **Oops! Undo** | `U` | ↩️ Oops! Button |
| **Magic Wand** | `M` | 🪄 Magic Wand Button |
| **Pause** | `P` or `Esc` | ⏸️ Button |
